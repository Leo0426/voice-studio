Voice Studio 将文字转语音、语音转文字和个人任务历史整合到 macOS 工作台。

## 新增

- **本机账号工作台**。客户端自带本机服务。首次启动时，从窗口工具栏复制首次设置码，再创建管理员账号。
- **本地语音转写**。可以录制麦克风音频或选择已有文件，使用 Whisper 转写。首次使用时下载模型。
- **可选 OpenAI 引擎**。在账号中心设置 API Key 后，可使用云端语音合成和转写。内置音色试听可离线播放。
- **Qwen 多角色对话**。为不同角色分配音色，按顺序合成每句台词。新完成的设备合成可在个人任务历史中查看。

## 安装

适用于 Apple Silicon（M1 及以上）和 macOS 14 或更新版本。下载 `VoiceStudio-v0.1.2-arm64.zip`，解压后将 `Voice Studio.app` 拖入「应用程序」。ZIP 的 SHA-256 见同名 `.sha256` 文件。

应用使用 ad-hoc 签名，未经 Apple 公证。如果 macOS 阻止首次打开，校验下载文件的 SHA-256 后，可在「系统设置 → 隐私与安全性」中选择「仍要打开」。

本地 Qwen 和 Whisper 模型需要单独下载。麦克风录制需要授予 macOS 麦克风权限。
